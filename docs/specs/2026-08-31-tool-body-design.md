## Problem Statement

模块③ 目前只交付**齿圈**（`toolRing` 图层，`build_tool_ring`，K-3.1 前半「单齿实体 → 周向阵列」）。设计书 K-3.1 后半「**与刀体（外径 d_at、内孔、端面）布尔并/差**」未实现——用户看到的是一圈悬空齿圈，没有刀体：没有装夹内孔、没有键槽、没有把刀齿连成整体的本体。刀具几何体面板 v1 曾明确禁入刀体结构（当时依据：W9 未回读）；现 W9 已回读，禁令前提消除，本 spec 解禁并以预览级落地。

## Solution

新建 `backend/core/envelope/tool_body.py`：以「闭环轮廓 → 刚体运动 → 盖帽」同族机制生成刀体网格，但轮廓是**双闭环**（外 = 谷底圆，内 = 孔圆±键槽缺口），端面用极角配对 quad-strip 剖分——环形区域不是简单多边形，`_ear_clip_indices`（单闭边界耳切）不适用；刚体运动为纯轴向直拉伸。同时输出**解析描述包**作为权威数据。`/tool-ring` 端点扩展为一次返回齿圈 + 刀体两个几何；前端步骤3 面板新增「刀体结构」参数分组 + `toolBody` 图层。参数全部**表驱动**（手册标准系列下拉），校验软硬分流。

## 几何设计（构造六要点）

坐标标签 **T**（刀具系）。刀体与齿圈在同一坐标系、同一前刀面平面基准上拼合。

1. **外缘 = 谷底圆柱**：`r_outer = ToothLoop.root_radius`（`tooth_solid.py:68`，谷底圆弧半径水平，= r_limit − 径向偏置）。派生只读——用户填了必然与齿圈打架，故不披露。谷底弧凸侧背离轴（半径 ≥ r_root），刀体外圆柱恰在谷底最低点相接，预览级无穿插。
2. **前端面 = 前刀面平面按槽位折叠**：[23]§3.3②「内圈实体每区域前端面∥对应刀齿前刀面」。刀具整环 = 基准齿 ×z_t **纯旋转**阵列（旋转不改 z），41 个齿的前刀面全部停在基准齿窗口的 z 相位——刀体前端面若取理想平面会与齿圈产生十余毫米 z 错位（2026-08-31 用户实测「光滑透明椭球」根因）。故前端面 z 按 2π/z_t 折叠回基准齿窗口（`_make_phase_folder`），逐扇区与前刀面平行，与整环阵列同一近似等级，重磨不挡屑规则保持。
3. **纯轴向直拉伸**：loop 每点沿 −Z 平移 B（不旋转）。键槽是装键的，必须笔直；斜齿刀的**刀齿**才做螺旋扭转（`helical_sweep`），刀体不做。代价：β_t≠0 时刀体后端与刀齿后端存在微小错缝（预览级接受，正式级布尔自然消解）。
4. **键槽朝 +X**：刀具系 θ=0 方向（与既有 cap_face/相位约定一致）；预览级无功能语义。
5. **直孔**：内孔为圆柱面（主流盘形插齿刀 φ75~125 即直孔；小模数台阶孔不追）。
6. **成型机制同族、剖分不同**：刀体端面是**双闭环环形区域**（非简单多边形），不走 `_ear_clip_indices`（单闭边界耳切）；剖分用**极角配对 quad-strip**——内外边界对中心均星形（键槽缺口向外凸入材料侧），同一极角序列采样两条边界、逐角连四边形（键槽角点处放加密采样角）。侧壁 = 内外边界各自挤壁；前后端面各一条环带。刚体运动与齿圈同族（纯轴向平移）。刀体轮廓全解析（圆+直线段），网格离散仅为渲染细分。

## 描述包数据契约（权威源，CAD-neutral）

即设计书 §4.6.2 输出契约的刀体部分。GLB 是它的视图；正式级 OCCT 拿描述包原样重建，零信息丢失。

```python
# 请求参数（pydantic ToolBodyParams，并入现有 ToolRingRequest）
class ToolBodyParams(BaseModel):
    mounting: Literal["bore", "bore_keyway"]        # 法兰/带柄枚举位预留
    d_bore: float                                    # 内孔直径 [mm]，手册系列值
    keyway_b: float | None = None                    # 键槽宽 [mm]；None=按档自动带出
    keyway_t1: float | None = None                   # 键槽深 [mm]；None=按档 GB/T 6132 最近档值（见下表）
    B_body: float | None = None                      # 厚度 [mm]；None=档内 ≥L 最小标准值

# 响应中的解析描述包（ToolBodyDescription，随几何一并返回）
{
  "loop": {                       # 前刀面平面上的双闭环轮廓（解析定义，非离散点）：outer=谷底圆、bore=孔圆（±键槽缺口），端面 quad-strip 极角配对
    "outer_radius": r_root,       # 谷底圆柱半径（派生自齿圈）
    "bore_radius": d_bore / 2,
    "keyway": {"width": b, "depth": t1, "polar_deg": 0} | null,  # +X 方向
  },
  "rake_plane": {"A": .., "B": .., "C": .., "const": ..},   # 前端面所在平面（继承 RakeSurface）
  "extrusion": {"axis": [0, 0, -1], "length": B_body},       # 纯轴向直拉伸
  "boolean_def": {                                            # 正式级布尔定义（挂账执行）
    "union": ["tooth_ring"],
    "cut": ["bore_cylinder", "keyway_box" | null],
  },
  "grade": "preview",
}
```

## 参数披露与对档规则

### 手册标准数据（袁哲俊《齿轮刀具设计》，探查已入库）

盘形插齿刀结构尺寸表（PDF p.168-170 表 4-12~4-16、p.179 表 4-32；小模数 JB/T 3095）：

| 公称分度圆档 | 内孔 d_i [mm] | 键槽宽 b [mm] | 厚度 B [mm]（按模数段） |
|---|---|---|---|
| φ40（小模数） | 15.875 | 6（m≤0.6）/ 7（m≥0.7） | 10 / 12 |
| φ63（小模数） | 31.743 | 6 / 7 | 10 / 12 |
| φ75 | 31.743 | 10 | 15（m1~1.5）/ 17（1.75~2.75）/ 20（3~4） |
| φ100 | 31.743（可选 44.443） | 10（m1~1.5）/ 12（1.75~6） | 18 / 22 / 24 |
| φ125 | 31.743（可选 44.443 / 44.45） | 13 | 30 |
| φ160 | 88.9 | 18 | 35 |
| φ200 | 101.6 | 20 | 40 |

刀齿强度允许最小厚度 B_min（表 4-6）与内孔公差（表 4-29）已记录，供后续批次。

注：碗形 φ50 档（孔 20）不进本应用对档——装夹范围（Q2）不含碗形，该孔径在界面不可达，仅作手册数据留档。

### 键槽深 t₁（GB/T 6132 / ISO 240:2016 Table 1，2026-08-31 当日回读）

手册只给键槽宽不给深。深度取自 **ISO 240:2016（GB/T 6132 采标）Table 1 跨距尺寸**：孔侧槽深 `t = c1 − d`，按最近档近似映射（驱动键体系，槽宽 C11 松配合——与刀具装夹性质一致；备选 GB/T 1095 传力键体系 t2 值偏深，如 b=10→3.3 vs 2.8，不采用但留档）：

| 内孔 d_i | GB/T 6132 最近档 | 孔侧槽深 t₁ [mm] | 备注 |
|---|---|---|---|
| 15.875 | d=16（a=4） | **1.7** | 键宽不匹配（档宽 4 vs 手册 6/7），取深度值 |
| 20 | d=19/22 | **2.1** | 无 d=20 档 |
| 31.743 | d=32（a=8） | **2.8** | |
| 44.443 / 44.45 | d=40/50 | **3.5** | 两档同值 |
| 88.9 | d=80（a=18） | **5.5** | 键宽恰好匹配 |
| 101.6 | d=100（a=25） | **7.0** | 键宽不匹配，取深度值 |

来源：ISO 240:2016 官方预览全表（iTeh）+ GB/T 6132-2021（openstd 现行）+ GB/T 1095-2003 全表交叉核对；GB/T 6081 自身键槽深表公开网络未获取（留档）。UI 标注「按 GB/T 6132 最近档」。

### 对档规则（Q8 裁决）

车齿刀分度圆 `d_pt = 2·r_pt` 是连续值，手册按公称分度圆分档：

- **内孔向下取档**：取 `档 ≤ d_pt` 的最大档；`d_pt` 低于最小档（φ40）时钳制到 φ40 档。安全侧逻辑：孔小了顶多重配刀杆，孔大了刀体裂。
- **厚度 B 默认** = 当前档标准系列中 **≥ L 的最小值**；该档系列全 < L 时黄警「超出该档标准厚度」并放行非标值（仍须 ≥ L，硬校验）。
- **键槽宽 b** 随（档 × 模数段）自动带出；专家模式可覆盖。

### 面板交互（Q12 裁决 + ADR-020 ④）

「刀体结构」独立分组，组内三档：

| 档 | 参数 | 控件 |
|---|---|---|
| 必填 | 装夹形式 | 枚举下拉（bore / bore_keyway） |
| 必填 | 内孔直径 d_bore | 下拉（对档表过滤后的系列值） |
| 可默认 | 键槽宽 b / 键槽深 t₁ / 厚度 B | 自动带出，专家模式可覆盖 |
| 导出量 | 刀体外缘直径（=2·r_root）、容屑槽数（=z_t） | 只读展示，标「由上游决定」 |

### 校验清单（Q10 裁决：软硬分流）

| 校验 | 级别 | 处置 |
|---|---|---|
| 孔缘越谷底圆（r_bore ≥ r_root；带键槽时按键槽底 r_bore + t₁ 计） | 硬 | 后端 400（前端下拉已预过滤，此为二道闸） |
| B < L（刀齿比刀体长） | 硬 | 后端 400 |
| B 非当前档标准值 | 软 | 黄警不阻断（ADR-020 ① 区间联动语义） |
| 键槽深为最近档近似 | 信息 | UI 标注「按 GB/T 6132 最近档」（W16 已销，映射非逐档精确） |

## 端点与数据流

- `POST /api/envelope/tool-ring` 扩展：请求并入 `ToolBodyParams`；一次管线原则下刀体始终生成，缺省值 = `mounting: "bore"` + 对档表默认孔径 + 档内默认厚度；响应追加 `{ "body_layer": { "id": "toolBody", "glb_base64": .. }, "body_description": ToolBodyDescription }`。
- 前端：`useToolParams` 单例扩展刀体参数；`layerPalette.ts` 注册 `toolBody`（配色与齿圈区分、同族金属色）；切入步骤3 预设 = toolRing + toolBody（ADR-020 ③ 修订）。
- 生成触发：与齿圈共用现有生成按钮，一次管线出两几何（Q3 裁决，原子性）。

## 测试策略（ADR-007 分层）

1. **纯数学单测（CI 可跑，无 OCCT）**：
   - 对档规则：边界值（d_pt 恰在档界、低于 φ40 钳制）；
   - 厚度默认：档内 ≥L 最小值、全 <L 黄警分支；
   - 校验规则：孔缘越谷底圆 / B<L 拒绝矩阵；
   - 轮廓解析正确性：孔圆半径、键槽缺口位置（+X）、外缘=r_root；
   - 网格闭合性：端面 quad-strip 环带完整、闭合流形判据（每边恰被两三角反向共用）+ 有向体积 > 0。
2. **golden 回归（硬编码常量）**：算例1/2 参数下 toolRing+toolBody 双几何顶点数 / 有向体积 / 描述包字段快照。
3. **前端**：图层预设单测（切入步骤3 后 toolRing+toolBody 可见）、分组披露三档渲染。
