# 离散包络（子 PRD-2）实现 Spec

**日期**：2026-08-13
**父 PRD**：`../prds/2026-08-13-envelope-calculation-prd.md` → `envelope/02-discrete-envelope.md`
**状态**：待实现
**来源**：grilling 访谈（12 决策全 A + Q1 方法论修正）+ 设计书第 2/3/4/6/8 章 + 算例2/3 JSON 回归向量 + 5 路一致性审计

## Problem Statement

模块① 只交付了「工件齿轮」的几何。模块② 的「反向包络」——由工件齿廓点云经运动包络反推出刀具的产形面与刃形——尚未实现。子 PRD-1 已把 3D 视口升级为「多图层叠加」、后端具备「曲面片/曲线/点云 → GLB」导出能力，但**没有任何真实包络几何可填**。本子 PRD 要落地离散包络路线（K-2.9~K-2.13）：让用户输入刀具参数后，系统真正算出「产形面（扫掠点云三角网）」与「刃形（有序多段空间曲线）」，叠加到视口上，并以量化诊断（ffα、覆盖判据）支撑用户目检「只相切、无重合/干涉/折叠」。

## Solution

补齐模块② 的离散包络内核：`transforms.py` 补 K-0.5 运动链，新建 `process_plan.py`（K-1.4~1.8 安装方案）、`gen_surface.py`（K-2.9~2.11 点云→产形面）、`edge.py`（K-2.11 内边界→刃形 + K-2.12 覆盖 + K-2.13 ffα）。前端加最小刀具参数区 + 两个端点驱动，产形面/刃形两图层叠加 + 诊断条。**验收哲学**：文献值为「参考基准」（非硬门禁），正确性靠双向包络自证闭环 + 几何不变量 + 可视化目检。

## User Stories

1. 作为车齿刀设计人员，我希望在步骤2 输入刀具参数（z_t/β_t/j_t/γ₀/α₀）后点「开始包络」，看到产形面（品牌蓝半透明网面）先叠加、刃形（珊瑚红曲线）后叠加，理解「刀具几何如何从包络中诞生」。
2. 作为车齿刀设计人员，我希望产形面以**三角网面**呈现（非散点），能一眼看出扫掠包络「只相切、无折叠/重合/干涉」。
3. 作为车齿刀设计人员，我希望刃形以**逐点生长动画**出现，且左右两条刀刃各自生长、中间断开处不硬连。
4. 作为车齿刀设计人员，我希望诊断条显示 ffα 与覆盖判据两个数，成功绿勾、失败红叉，据此判断算得对不对。
5. 作为开发者，我希望 K-0.5 运动链、K-1.4~1.8 安装方案、K-2.9~2.13 内边界/覆盖/ffα 是**纯 Python 纯数学**、可入 CI，不依赖 OCCT。
6. 作为开发者，我希望回归测试以算例2 的矩阵/单点轨迹、算例3 的参数自洽为「参考基准」，并以双向包络自证闭环兜底正确性。

## Implementation Decisions

### 验收哲学：文献值是参考基准，非硬门禁（跨子 PRD 方法论，ADR-019）
- 文献（含设计书复算）数值**不作为「分毫不差否则红」的死门禁**——论文可能笔误（设计书已抓出 C2 中心距符号、C3/C11 Σ 翻号、W13 内齿轮取'+'、以及本 spec 下方「算例2 传动比 i 符号」一例）。
- 正确性由三层保证：① **双向包络自证闭环**（K-2.13 用算出的刃形反向复现工件齿形，误差小即逻辑自洽）；② **几何/物理不变量**（如 a = r_pw − r_pt 自洽、转速比 = z_w/z_t）；③ **可视化目检**（产形面无折叠、刃形只相切、无重合/干涉——用户可直接观察判断）。
- 文献值退化为「参考基准」：回归测试用它做对照，设**合理容差**；超差时**先查文献笔误**（对照 C2/C3/W13），而非立即判 bug。
- ⚠️ **ffα 自证闭环只证「闭环自洽」、非「绝对正确」**：若正向与反向共享同一处变换符号 bug（如中心距 a 符号、Σ 旋向），ffα 仍会趋近 0 而「自己骗自己」。因此变换链的绝对正确性必须**额外依赖算例2 矩阵/单点轨迹参考值的独立校验**——两者都过才算完整。

### 算法管线一：运动链（K-0.3/0.4/0.5，补齐 transforms.py）
- **K-0.3 安装变换**（F_t → F_w，含刀具轴倾斜角 δ）：`M_{F_w,F_t} = Tran(x,a)·Rot_x(Σ)·Rot_y(δ)`；逆 `M_{F_t,F_w} = Rot_y(−δ)·Rot_x(−Σ)·Tran(x,−a)`。
- **K-0.4 动系旋转**：W 相对 F_w = `Rot_z(φ_w)`；T 相对 F_t = `Rot_z(φ_t)`（φ 有符号，U6）。
- **K-0.5 统一工件→刀具链**：`r^(T) = Rot_z(−φ_t−Δφ_t)·Tran(z,−s_t)·M_{F_t,F_w}·Tran(z,s_w)·Rot_z(φ_w)·r^(W)`。
- **离散包络退化**（Δφ_t=0、s_t=s_w=0、δ=0，即 [21] 式(7)）：
  `r^(T) = Rot_z(−φ_t)·Rot_x(−Σ)·Tran(x,−a)·Rot_z(φ_w)·r^(W)`
  其中 `φ_w = ω_w·t`、`φ_t = ω_t·t`，`ω_w/ω_t = z_t/z_w`（β_w=0 时，K-1.7 差动项为零）。
- 现有 `transforms.py` 已有 `rot_x/rot_y/rot_z/tran_x/tran_y/tran_z`（K-0.1/0.2）与 `helical_surface`（K-0.6）、`extract_rotation_3x3`（K-0.7）。本子 PRD 补两个纯函数：
  - `install_transform(a: float, Sigma: float, delta: float = 0.0) -> Mat4`（K-0.3，返回 `M_{F_w,F_t}`）
  - `workpiece_to_tool_chain(r_w, phi_w, phi_t, a, Sigma, *, delta_phi_t=0.0, s_t=0.0, s_w=0.0, delta=0.0) -> NDArray`（K-0.5 广义链，退化时 delta_phi_t/s_t/s_w/delta 取默认 0；内部调 `install_transform` 的逆）

### 算法管线二：工艺方案（K-1.4~1.8，新建 process_plan.py）
- **输入**：工件（z_w, β_w, j_w, k_io, m_n）+ 刀具（z_t, β_t, j_t）。
- **输出** `ProcessPlan{Σ, a, r_pw, r_pt, i, ω_ratio}`：
  - K-1.4 `Σ = j_w·β_w − j_t·β_t`（U8，有符号）
  - K-1.5 `a = r_pw + k_io·r_pt`（内齿轮 k_io=−1 → a = r_pw − r_pt）
  - K-1.6 `r_pt = r_pw·z_t·cosβ_w/(z_w·cosβ_t)`
  - **同步比**（K-1.7，恒正、滚动啮合）：`omega_ratio = ω_t/ω_w = z_w/z_t`（β_w=0；β_w≠0 斜齿本子 PRD 禁用，s_d 判定表 T2 未销项）
  - **传动比**（[25] 式(3)，含内外啮合方向）：`i = −k_io·z_w/z_t`
  - `r_pw = m_t·z_w/2`，`m_t = m_n/cosβ_w`
- **两个量的区别（务必分清）**：`ω_t/ω_w = z_w/z_t` 恒正（角速度比值，滚动啮合）；`i = −k_io·z_w/z_t` 含 k_io 因子、外齿轮为负、内齿轮为正（传动比方向约定）。K-0.5 运动链只用 φ_w/φ_t 的实际值，不用 i。
- **算例2 参考值**（j_t=−1 左旋 → Σ=+15°；m_n 反推 0.399635）：Σ=15°、a=6.7938、r_pw=20.3814、r_pt=13.5876、ω_t/ω_w=z_w/z_t=1.5、**i=−k_io·z_w/z_t=+1.5**（内齿轮 k_io=−1。⚠️ 设计书第3章 §3.3 把算例2 标为 i=−1.5 系**笔误**，与同章公式 `−k_io·z_w/z_t` 及第6章 §6.3 算例3 内廓形 i=+20/11 自洽矛盾；按第4章 K-1 伪代码与算例3 取 +1.5）。
- 失败模式：a ≤ 0 拒绝；Σ=0 拒绝（刮齿需轴交角）；β_w≠0 时返回 400（MVP 禁用斜齿）。

### 算法管线三：离散包络（K-2.9~2.13，新建 gen_surface.py / edge.py）
- **K-2.9 运动包络点云**：对 m 个离散采样点，工件廓形 n 个点经 K-0.5 退化链变换，得 m×n 点云 `cloud`（坐标 T）。**采样语义**：`θ_range`（第3章 §3.5）是**刀具转角 φ_t** 的扫描范围；`φ_t = linspace(−θ_range, +θ_range, m)`（含两端点与 φ_t=0 正中位置），`φ_w = φ_t·z_t/z_w` 由同步关系导出。点云索引 `cloud[i][j] = (φ_t[i], profile[j])`。
- **K-2.10 投影**：z=0，投影至 XOY 平面。
- **K-2.11 内边界提取（默认 [25] 径向圆环法，NR=200）**：以 **O_c = 刀具轴 = T 系原点 (0,0)** 为圆心（K-0.5 的 `Tran(x,−a)` 已把工件廓形点从「距刀具轴 a」移到刀具系原点，故投影后刀具轴即原点），设 NR 个均匀半径圆环；每环取距 X_c 轴最近两点（M1、M2，即 y 最接近 0 的两侧点）→ 刃形点。产出**左右两条刃形**（每条有序，齿顶/齿根处断开）。
- **K-2.12 覆盖判据**：工件廓形每一离散点（n 个）必须在离散区间内对应一个刃形点。**配对规则**：对每个工件廓形点，在刃形点集（NR 环提取）中找「半径最接近」的刃形点；若最近径向距离 > 环间距阈值（= NR 环的半径步长），判未覆盖。未覆盖点记入 `coverage_report.uncovered`。
- **K-2.13 双向包络复算 ffα**：以所得刃形**正向包络**复现工件齿形，逐点法向距离得 ffα（形状偏差）。**正向包络函数落 `envelope` 模块**（为 K-4.1 雏形，模块④ 正式化时复用）：
  - 反向（K-2.9 已用）：`r^(T) = Rot_z(−φ_t)·Rot_x(−Σ)·Tran(x,−a)·Rot_z(φ_w)·r^(W)`
  - 正向（K-2.13 用其逆，`transforms.tool_to_workpiece_chain`）：`r^(W) = Rot_z(−φ_w)·Tran(x,+a)·Rot_x(+Σ)·Rot_z(+φ_t)·r^(T)`
  - **MVP 实现** `forward_envelope_ffa(edge_pts, profile_pts, plan) -> float`：刃形点（内边界 = 工件廓形在刀具系 φ_t=0 的映射）经 `tool_to_workpiece_chain(0,0,a,Σ)` **φ_t=0 静态**正向变换回工件系，与目标工件廓形逐点径向距离取最大 → ffα [μm]。此为**简化自证闭环**（证正向=反向逆、非绝对正确）；完整「扫掠 + 内包络」（刃形点随 φ_t/φ_w 同步扫掠取轨迹族内包络，[21] 步骤(5)）属模块④ K-4.1，届时复用 `tool_to_workpiece_chain`。
- 离散参数默认（第3章 §3.5，后端默认、不暴露 UI）：n=200 / m=181 / NR=200 / θ_range=±20°。

### 数据契约
- **ProcessPlan**（`process_plan.py`）：`{Σ, a, r_pw, r_pt, i, ω_ratio}`，坐标无关的标量方案（定义见上）。
- **GeneratrixSurface**（`gen_surface.py` 输出）：`{cloud: m×n 点云（坐标 T）, mesh: 三角网, layer_id='generatrix'}`。**三角网连片规则**：点云索引 `cloud[i][j]=(φ_t[i], profile[j])`，每格两个三角片 `{(i,j),(i+1,j),(i,j+1)}` + `{(i+1,j),(i+1,j+1),(i,j+1)}`。**mesh 是原始扫掠点云（K-2.9，含 z 分量）的直接三角化，不是投影内边界结果**——刃形是投影 z=0 + 内边界提取（K-2.10~2.11）的另一步结果，另行导出为 LINE_STRIP。
- **EdgeCurve**（`edge.py` 输出）：`{segments: [{pts: [(x,y,z), ...] 有序, continuity: 'continuous'|'discontinuous'}], coverage_report, ffa_um}`。**多段**：左右刃形各一段（各段内连续；段间在齿顶/齿根处断开，由多段结构体现——设计书 §6.3「刃形在 M 点处不连续」）。坐标 T（z≈0，投影刃形）。
- **coverage_report**（K-2.12 输出，EdgeCurve 与 edge 端点共享）：
  ```
  { total_points: n, uncovered: [{profile_idx: int, radius: float}], coverage_ratio: float, pass: bool }
  ```
  基准维度 = n（工件廓形离散点数）；`coverage_ratio = 1 − len(uncovered)/n`；`pass = (len(uncovered)==0)`。
- **溯源**：所有导出量带 `source` 标记（[21]/[25]/推导），供测试与审计（§1.4 溯源字段）。

### 端点设计（独立算、无状态）
- `POST /api/envelope/generatrix` 与 `POST /api/envelope/edge`，**独立计算、不缓存**：edge 端点重算一遍点云（m×n 矩阵乘法，毫秒级可忽略），换取后端无状态（对齐 ADR-018「每阶段独立 GLB、无跨阶段攒状态」）。
- **请求体共用**（JSON 字段逐项枚举）：
  ```json
  {
    "workpiece": { "k_io": -1, "m_n": 2.0, "z_w": 82, "beta_w_deg": 0.0, "j_w": 1,
                   "alpha_n_deg": 20.0, "h_an": 1.0, "c_n": 0.25, "x_w": 0.0, "b_w": 20.0 },
    "tool": { "z_t": 68, "beta_t_deg": 15.0, "j_t": -1, "gamma_0_deg": 5.0, "alpha_0_deg": 8.0 },
    "discretization": { "n": 200, "m": 181, "NR": 200, "theta_range_deg": 20.0 }
  }
  ```
  - `workpiece` 字段 = `GearParams` 的子集（重建廓形点云所需，`β_w` 限定 0）；`discretization` 可缺省走默认。
  - `tool.gamma_0_deg`/`alpha_0_deg` 为**保留位、本子 PRD 忽略**（前角属 ②a 前刀面、后角属 ②c 后刀面，均 Out of Scope）：仅做 schema 校验与透传，不接入任何公式。
- **响应体**：
  ```json
  // generatrix
  { "layer": { "id": "generatrix", "glb_base64": "..." }, "coord_frame": "T" }
  // edge
  { "layer": { "id": "edge", "glb_base64": "..." }, "coord_frame": "T",
    "coverage_report": { "total_points": 200, "uncovered": [], "coverage_ratio": 1.0, "pass": true },
    "ffa_um": 0.05, "segments_meta": [{ "count": 100, "continuity": "continuous" }, { "count": 100, "continuity": "continuous" }] }
  ```
- **坐标标签**：响应显式携带 `coord_frame: "T"`（所有几何在刀具动系 T，满足「坐标标签随数据传递、无标签视为非法」§1.4；GLB `node.name` 仍仅作调试标签）。
- 错误契约 `{ "error": "描述", "code": 400 }`；模型传输仅 glTF/GLB。

### 前端交互
- **最小刀具参数区**（步骤2「包络解算」内，风格与现有步骤条一致）：z_t、β_t、**j_t（旋向 ±1）**、γ₀、α₀（默认=算例1 值 z_t=41/β_t=15°/j_t=−1/γ₀=5°/α₀=8°，匹配端到端 demo 的 z_w=82 内齿轮）+「开始包络」按钮。工件参数沿用步骤1 已填值。
- **驱动顺序**：点「开始包络」→ 依次调 generatrix、edge 端点 → 经 `gear:layer-ready` 事件（子 PRD-1 已建）叠加产形面、刃形两图层。
- **产形面图层**：`generatrix`（品牌蓝半透明三角网面）。
- **刃形图层**：`edge`（珊瑚红多段 `LineSegments`），**逐点生长动画**（`drawRange` 顶点 0→N，各段各自生长）。
- **诊断条**（步骤2 内容区底部，常驻非弹窗）：ffα（<0.1μm）、覆盖判据（100%，读 `coverage_report.pass`），成功绿勾+数值 / 失败红叉+数值；**无失败补救按钮**（「增大转角扫描」「加密离散」等升级路径留后续子 PRD）。
- **离散参数不暴露 UI**：n/m/NR/θ_range 用后端默认值；等失败升级路径需要改参数时再暴露。

### 工件廓形输入（端到端跑管线用哪个齿轮）
- **安装参数/变换链的「参考基准」**：用算例2 的 Σ=15°、a=6.7938、z_w=102、z_t=68、r_pw=20.3814、r_pt=13.5876（这些只依赖安装参数与运动，与齿廓是「三圆弧」还是「渐开线」**无关**）。
- **端到端包络管线**：用**真实渐开线内齿轮**（标准参数，如 m_n=2、z_w=82、α_n=20°、β_w=0、k_io=−1）跑完整 K-2.9~2.13，产形面 + 刃形叠加目检。算例2 的三圆弧齿廓未发表（T4），留到用户导 CAD 点云时接入。
- 三层解耦：① process_plan 正确性 → 算例2 Σ/a/r_pw/r_pt 参考回归；② K-0.5 变换链 → 算例2 矩阵/单点轨迹参考回归；③ 端到端管线 → 任意渐开线内齿轮 + ffα 自证闭环 + 目检。

- **参考基准（非硬门禁）**：
