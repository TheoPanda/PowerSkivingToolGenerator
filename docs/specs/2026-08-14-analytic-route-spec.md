## Problem Statement

离散路线（子 PRD-2）用「扫点 + 内边界」近似算出刃形，通用但精度只靠 ffα 自证闭环兜底——正向/反向共享同一变换链时符号 bug 会互相抵消（`edge.py` 已明示「只证闭环自洽、非绝对正确」）。解析路线（K-2.6~2.8）用公式精确算「产形面 ∩ 前刀面」得刃形，为标准渐开线工况提供高精度 + 理论修正支撑，并与离散路线**双路线互检**，打破「自己验证自己」的循环。本子 PRD 落地解析共轭路线 + 第5章 §5.5 互检。**内外齿轮通用**（k_io 无关，见研究结论）。

## Solution

新建 `analytic.py`（K-2.6 生成面 + K-2.7 啮合方程 + K-2.8 Newton 求交 + 双路线互检）。注册 analytic 端点 + 双路线对拍。验收靠双路线互检 ε_cross + 几何不变量 + 算例1 输入自洽 + 目检（刃形点坐标无文献锚点，T5）。

## User Stories

1. 作为车齿刀设计人员，我希望在标准渐开线工况下用解析路线精确算出刃形，得到比离散路线更平滑、有理论支撑的刀刃曲线。
2. 作为车齿刀设计人员，我希望系统对同一工件独立跑「解析 vs 离散」两条路线并逐点比较，偏差超限时报警，从而暴露符号错误。
3. 作为车齿刀设计人员，我希望内外齿轮（k_io=±1）都能走解析路线，不用关心符号差异（公式 k_io 无关）。
4. 作为车齿刀设计人员，我希望解析路线发散/刃形交叉时被明确提示，并能一键转离散路线。
5. 作为开发者，我希望 K-2.6/K-2.7/K-2.8 是纯 Python 纯数学、可入 CI。
6. 作为开发者，我希望双路线互检 ε_cross=1μm 作为「两法一致」判据，配合几何不变量兜底。
7. 作为开发者，我希望外齿轮解析用 P0 组合（互检 + ex3 硬断言 + 内齿轮对称性）兜底，并显式标注无文献 golden（T14）。

## Implementation Decisions

### 验收哲学（继承 ADR-019 + 研究结论）
- 解析路线 **k_io 无关**：同一套 K-2.6~2.8 公式，k_io 只经中心距 `a = r_pw + k_io·r_pt`、传动比 `i = −k_io·z_w/z_t`、工件齿面（齿槽/齿廓，模块①）三处进入，全在已实现的 `process_plan.py` / 模块①，不渗透进矩阵/啮合方程/前刀面符号。
- **golden 锚点薄弱是核心约束**：K-2.6~2.8 的刃形点坐标文献未发表（T5），算例1 的八项硬锚点（[23] 表3.3）是**修正链 K-2.23~2.25** 的产物、另行立项。故本子 PRD 的绝对正确性只能靠「双路线互检 + 几何不变量 + 输入自洽 + 目检」组合兜底。

### 算法管线一：K-2.6 生成面（共轭面 = 产形面）
- 两条文献链（Tsai [10] 式(11) / Guo [11] 式(1)(27)）最终**归一 K-0.5 统一链**（设计书 §4.3.3「离散化统一用 K-0.5」），不分别落地。
- 生成面 = 工件齿面经共轭变换的参数化曲面；内外齿轮区别 = 中心距 a 的 ± + 工件齿面（模块①），矩阵本体不变。
- 输出 `ConjugateSurface{参数化曲面, 坐标 T}` = 严格意义的产形面。

### 算法管线二：K-2.7 啮合方程
- 主实现 `n·v¹² = 0`（[24] 式(2-14)，矢量不变式，k_io 无关）。
- 三种文献形式（[10] 式(15)、[3] 式(3)、[14] 式(19)）作交叉验证，兜符号错。

### 算法管线三：K-2.8 刃形求交
- 刃形 = 生成面 ∩ 前刀面：对每个工件廓形点 u_i 求 θ 使 `g(θ) = S_c′(u_i, θ, t) − S_R = 0`（[25] 式(8)）。
- Newton-Raphson + 延拓初值（首点 `θ₀ = atan2(y_i, x_i)`）；收敛判据 `|g(θ)| < ε_NR`、`N_max = 50`。
- 发散/超限 → 按失效表提示转离散路线（设计书 §4.3.6）。

### 双路线互检（第5章 §5.5）
- 解析 vs 离散独立算刃形，对应弧长位置法向距离 `max|Δ| < ε_cross = 1μm`（推导设定，算例1 实测校准后固化，T1 纪律）。
- 不一致处理：先加密离散参数复算；仍不一致 → 查解析路线啮合方程（对照 K-2.7 其余文献形式交叉验证）。
- 算例2 型纯离散工况无互检对象 → 以 K-2.13 正向复算 + K-2.12 覆盖判据替代。

### 数据契约
- 输入：同子 PRD-2（workpiece + tool）+ `method=analytic` + NR 参数（k_io 经 workpiece 传入，公式本体 k_io 无关，不新增内外分支）。
- 输出：同一 `EdgeCurve` 结构（解析/离散对偶，下游不感知路线差异）+ `ConjugateSurface`。

### 端点设计（独立算、无状态）
- `POST /api/envelope/analytic`，独立计算、不缓存（对齐 ADR-018）。
- 响应：`layer.id='edge'`（解析刃形，与离散刃形同构同 LayerId）+ `coord_frame='T'` + `segments_meta` + 可选双路线互检偏差（`cross_check: { max_delta_um, pass }`）。

### 前端交互
- 高级选项：双路线对拍（可选，默认只跑 auto 推荐的单路线，避免耗时翻倍）。
- 一致性偏差并排展示（解析 vs 离散法向距离）。

## Testing Decisions

- **纯数学 pytest CI（不依赖 OCCT）**：K-2.6 生成面参数化、K-2.7 啮合方程、K-2.8 Newton 求根、互检法向距离，全部纯 NumPy/math。
- **双路线互检（主判据，相对正确）**：`max|Δ| < ε_cross=1μm`（先 assert 占位，算例1 实测校准后固化，T1 纪律；不写进单测硬锚点）。
- **几何不变量**：`a = r_pw + k_io·r_pt` 自洽、同步比 `ω_t/ω_w = z_w/z_t` 恒正、算例1 产形轮几何（d_1=84.91 / d_b1=79.456 / m_t=2.070552 / α_t=20.6469°）输入自洽（module ① 侧，非 K-2.6~2.8 输出锚点）。
- **外齿轮 P0 组合**（T14）：外齿轮解析↔离散双路线互检（ε_cross）+ ex3 外廓形硬断言（a=62.857 / i=−7/9）+ 内齿轮算例1 对称性兜底。
- **端点集成**：TestClient 调 analytic 端点，验 GLB magic、coord_frame='T'、node.name='edge'、segments_meta 结构（沿用子 PRD-2 端点测试模式）。
- **零回归门禁**：子 PRD-1/2/3/4 已交付保持全绿。
- **人工目检**：解析刃形平滑、无发散/交叉/自交（ADR-019）。
