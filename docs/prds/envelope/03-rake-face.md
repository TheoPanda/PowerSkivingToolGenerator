# 子 PRD-3：②a 前刀面定义

**父 PRD**：`../2026-08-13-envelope-calculation-prd.md`
**状态**：待评审
**依赖**：子 PRD-1（多图层基础设施）

## 1. 目标

实现模块②a 前刀面定义，产出 `RakeSurface`（隐式方程 F(x,y,z)=0 + 法矢场 n_rake），并在视口以半透明平面 + 法矢箭头展示。

前刀面是**独立设计输入**（非共轭派生物，设计书 §4.2.1）：刃形 = 共轭生成面 ∩ 前刀面（②b），后刀面 = 刃形 + let-off 运动（②c）。**v1 权重**：离散路线（子 PRD-2）下刃形经投影 z=0 → 内边界直接得、**不经前刀面**，故 v1 前刀面 = 可视化 + 算例1 系数自证；真正的「前刀面 ∩ 生成面 = 刃形」求交价值在子 PRD-5 解析路线 K-2.8 落地时兑现，其对法矢场 n_rake 的依赖由子 PRD-5 自行声明。

## 2. 范围

**做**：
- **K-2.1 平面前刀面（产形轮法，[23] 式3.4）**——算例1 有数值系数锚点，v1 唯一落地路径。
- `rake_type` 平面默认；γ₀ 默认 5°（参数字典，算例1/2 均 5°，[21] 表1 / [23] 表3.3）。

**不做**：
- K-2.3 通用方程 + 特征点（[25] S_R+P）——与 K-2.1 是**并列**装配路径（非其泛化/特例），v1 灰置 skeleton+assert 占位。
- 锥面前刀面 K-2.4（W5 未销项 → skeleton+assert 占位）。
- K-2.2 变换构造（[11]，圆柱刀 z_off 装配，二期可选）、K-2.5 法矢旋转链（模块④ 工作角度校核需要，本子 PRD 不接）。

## 3. 数据契约

- **输入**：`RakeSpec{rake_type, γ₀}` + `ToolDraft{β_t, z_t, …}`；r_pt 取自 ProcessPlan。
  - K-2.1 系数装配映射：β₁ = β_t（产形轮螺旋角 = 刀具螺旋角）、r₁ = r_pt（产形轮分度圆半径 = 刀具分度圆半径）。
- **输出**：`RakeSurface{F(x,y,z)=0, n_rake}`，坐标 T（[23] 下标 S₁ ≡ U4 刀具动系 T，同名同体，无变换）。
  - P_ref = (r_pt, 0, 0) 为 K-2.1 **自动装配**的过点（过产形面分度圆），非用户字段；const = −A·r_pt 由其展开。
  - n_rake = ∇F/|∇F|，**不额外翻号**；「指向刀体 vs 切屑」的方向语义留给子 PRD-5 K-2.8 消费时定。

## 4. 交互与视觉

- 前刀面图层：琥珀橙 #E8963A 半透明（α≈0.45）平面 + 法矢箭头。
- 参数输入：`rake_type` 仅「平面」可选；「方程」（K-2.3）、「锥面」（K-2.4）灰置占位（未销项，仅 skeleton+assert）、γ₀（默认 5°）。

## 5. 验收标准

1. 算例1 前刀面系数吻合 + 单位法向：A=0.087156 / B=0.257834 / C=0.962250 / const=−3.7002（K-2.1 回归），且 |(A,B,C)|=1（由 sin²γ + cos²γ = 1 构造保证，作为不变量断言）。
2. 前刀面在视口正确叠加；法矢箭头沿 n_rake 显示、方向与系数符号一致（**可视化目检**，对齐 ADR-019；不做数值断言，方向语义供 PRD-5）。

## 6. 缺口与风险

- W5（锥面前刀面 ±/∓ 未销项）→ 锥面 skeleton+assert 占位。
- 楔角校核（γ₀+α₀ < 90°−15°）**不在本子 PRD**：α₀ 是 ToolDraft 参数、非本子 PRD 输入；移交模块④ K-2.21 工作角度校核。
