# 子 PRD-3：②a 前刀面定义

**父 PRD**：`../2026-08-13-envelope-calculation-prd.md`
**状态**：待评审
**依赖**：子 PRD-1（多图层基础设施）

## 1. 目标

实现模块②a 前刀面定义，产出 `RakeSurface`（隐式方程 F(x,y,z)=0 + 法矢场），并在视口以半透明平面 + 法矢箭头展示。前刀面是**独立设计输入**（非共轭派生物），是单齿闭合（K-3.1，子 PRD-4）的前置；K-2.8 刃形交线（子 PRD-5 解析路线）对前刀面法矢场的依赖由子 PRD-5 自行声明。

## 2. 范围

**做**：
- K-2.3 通用方程（平面为特例，不依赖前角/刃倾角参数推导，规避 W5）。
- K-2.1 平面前刀面（[23] 式3.4，算例1 有数值系数锚点）。
- `rake_type` 平面默认；γ₀ 默认 5°。

**不做**：锥面前刀面 K-2.4（W5 未销项 → skeleton+assert 占位）、K-2.2 变换构造（二期可选）、K-2.5 法矢旋转链（工作角度校核需要，本子 PRD 不接）。

## 3. 数据契约

- **输入**：`RakeSpec{rake_type, γ₀}` + ProcessPlan。
- **输出**：`RakeSurface{F(x,y,z)=0, n_rake}`，坐标 T。

## 4. 交互与视觉

- 前刀面图层：冰蓝 #E8F0F8 半透明（α≈0.45）平面 + 法矢箭头。
- 参数输入：`rake_type`（平面/方程；锥面灰置占位——K-2.4 未销项 W5，仅 skeleton+assert）、γ₀。

## 5. 验收标准

1. 算例1 前刀面系数吻合（A=0.087156 / B=0.257834 / C=0.962250 / const=−3.7002，K-2.1 回归）。
2. 法矢场 ∇F/|∇F| 正确（供子 PRD-5 解析路线 K-2.8 Newton 使用，虽本子 PRD 不接）。
3. 前刀面在视口正确叠加、法矢箭头方向正确。

## 6. 缺口与风险

- W5（锥面前刀面 ±/∓ 未销项）→ 锥面 skeleton+assert 占位。
- 楔角最小阈值（γ₀+α₀ < 90°−15°）为工程默认，标注 ⚠️ 未销项，不写进单测硬锚点。
