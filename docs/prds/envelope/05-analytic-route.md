# 子 PRD-5：②b 解析路线 + 双路线互检

**父 PRD**：`../2026-08-13-envelope-calculation-prd.md`
**状态**：待评审（二期）
**依赖**：子 PRD-2（离散路线，作为互检基准）

## 1. 目标

实现模块②b 解析共轭路线（K-2.6~K-2.8），并落地设计书第5章 §5.5 双路线一致性互检，为标准渐开线工况提供高精度 + 理论修正支撑。

## 2. 范围

**做**：
- K-2.6 生成面（Guo 链）、K-2.7 啮合方程（主实现 [24] n·v¹²=0，其余三种文献形式作交叉验证）、K-2.8 刃形求交（Newton-Raphson，延拓初值，ε_NR/N_max 先占位后敏感性验证回填）。
- 设计书第5章 §5.5 双路线一致性互检（max|Δ| < ε_cross=1μm）。

**不做**：修正链 K-2.23~2.25（[23] 非对称修正，属 4.5 校核闭环，另行立项）、机床补偿 K-2.26/27（W7 缓行）。

## 3. 数据契约

- **输入**：同子 PRD-2 + `method=analytic` + NR 参数。
- **输出**：同一 `EdgeCurve` 结构（§1.4-4 解析/离散对偶，下游不感知路线差异）。

## 4. 交互与视觉

- 高级选项：双路线对拍（可选，默认只跑 auto 推荐的单路线，避免耗时翻倍）。
- 一致性偏差并排展示（解析 vs 离散法向距离）。

## 5. 验收标准

1. 算例1 产形轮几何复现（角度 < 0.005° / 直径 < 0.002mm，第7章行3）。
2. 双路线互检 max|Δ| < ε_cross=1μm（在算例1 实测校准后固化）。
3. （修正链 K-2.23~2.25 八项复现 + 修正前后刃形差 36μm→≤3μm 属 4.5 校核闭环，**另行立项**，不在本子 PRD 验收；父 PRD A6 归属同步修正。）

## 6. 缺口与风险

- T1（ε_NR/N_max 未固化）→ 敏感性验证后回填，此前 assert 占位、不写进单测硬锚点。
- T5（刃形坐标无锚点）→ 依赖设计书第5章 §5.5 互检 + 行3/4 参数锚点打破「自己验证自己」循环。
- W2（α₀=6° 反推假设）→ 数值闭环验证，正文确认待做。
