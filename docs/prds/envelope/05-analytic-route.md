# 子 PRD-5：②b 解析路线 + 双路线互检

**父 PRD**：`../2026-08-13-envelope-calculation-prd.md`
**状态**：待评审（二期）
**依赖**：子 PRD-2（离散路线，作为互检基准）+ 子 PRD-3（前刀面，供 K-2.8 求交）

## 1. 目标

实现模块②b 解析共轭路线（K-2.6~K-2.8），并落地设计书第5章 §5.5 双路线一致性互检，为标准渐开线工况提供高精度 + 理论修正支撑。**内外齿轮通用**：解析路线主体 k_io 无关（k_io 只经中心距 a / 传动比 i / 工件齿面三处进入，均不在 K-2.6~2.8 公式本体），详见研究 `docs/research/外齿轮解析路线.md`。

## 2. 范围

**做**：
- K-2.6 生成面（Guo 链）、K-2.7 啮合方程（主实现 [24] n·v¹²=0，其余三种文献形式作交叉验证）、K-2.8 刃形求交（Newton-Raphson，延拓初值，ε_NR/N_max 先占位后敏感性验证回填）。**内外齿轮共用同一套 K-2.6~2.8 代码，k_io 仅经 a/i/工件齿面三处进入（k_io 无关，不设内外分支）**。
- 设计书第5章 §5.5 双路线一致性互检（max|Δ| < ε_cross=1μm）。

**不做**：修正链 K-2.23~2.25（[23] 非对称修正，属 4.5 校核闭环，另行立项）、机床补偿 K-2.26/27（W7 缓行）。

## 3. 数据契约

- **输入**：同子 PRD-2 + `method=analytic` + NR 参数（k_io 经 workpiece 传入，解析公式本体 k_io 无关，不新增内外分支）。
- **输出**：同一 `EdgeCurve` 结构（§1.4-4 解析/离散对偶，下游不感知路线差异）。

## 4. 交互与视觉

- 高级选项：双路线对拍（可选，默认只跑 auto 推荐的单路线，避免耗时翻倍）。
- 一致性偏差并排展示（解析 vs 离散法向距离）。

## 5. 验收标准

1. 算例1（内齿轮）产形轮几何复现（角度 < 0.005° / 直径 < 0.002mm，第7章行3）。
2. 双路线互检 max|Δ| < ε_cross=1μm（在算例1 实测校准后固化）。
3. 外齿轮（k_io=+1）解析无文献 golden 锚点 → 用 P0 组合：外齿轮解析↔离散双路线互检（ε_cross）+ 中心距/传动比硬断言（ex3 外廓形 a=62.857 / i=−7/9）+ 内齿轮算例1 对称性兜底（详见研究文档）。
4. （修正链 K-2.23~2.25 八项复现 + 修正前后刃形差 36μm→≤3μm 属 4.5 校核闭环，**另行立项**，不在本子 PRD 验收；父 PRD A6 归属同步修正。）

## 6. 缺口与风险

- T1（ε_NR/N_max 未固化）→ 敏感性验证后回填，此前 assert 占位、不写进单测硬锚点。
- T5（刃形坐标无锚点）→ 依赖设计书第5章 §5.5 互检 + 行3/4 参数锚点打破「自己验证自己」循环。
- W2（α₀=6° 反推假设）→ 数值闭环验证，正文确认待做。
- 外齿轮解析无文献 golden 锚点（建议新增设计书第8章 T14 项）→ 所有解析文献（[23][11]）锚内齿轮，唯一含外廓形算例（[25] 算例3）走离散且刃形坐标未发表；用双路线互检 + ex3 硬断言 + 内齿轮对称性兜底，绝对正确性需额外一手数据（🟡 非阻塞）。
