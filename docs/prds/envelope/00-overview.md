## 跨子 PRD 共同约束（继承父 PRD）

1. **坐标标签随数据传递**（设计书 §1.4）：各几何均在刀具动系 T；无标签数据视为非法。
2. **错误契约** `{ "error": "描述", "code": 400 }`；模型传输仅 glTF/GLB。
3. **测试分层**：纯数学进 pytest CI（不依赖 OCCT）；OCCT 用集成测试（import 依赖 OCP，docstring 区分，不引入 `@pytest.mark.occt` marker）；回归基准以硬编码 golden 常量落地（对齐 CONTEXT.md ADR-007，`testdata/*.json` 后端接入留待几何端点充足后）。
4. **缺口纪律**：未销项 → skeleton + assert 占位，不当已验证公式用（backend/CLAUDE.md 第4条）。
5. **范围红线**：斜齿（β_w≠0）MVP 禁用；锥面刀变位族 / 多刃刀 / 机床补偿 / 工作角度校核缓行。
6. **符号体系**：内部 rad / 接口 °；变量名与设计书一致（w/t/F_w/F_t），禁止 1/2 表示工件/刀具。
7. **共享文件单一负责人**：`envelope/router.py`、`common/gltf_export.py` 等跨子 PRD 共享文件，统一写「修改（注册各自端点 / 复用导出函数）」，由最后合并的子 PRD 收口，避免「新增 vs 修改」歧义。
