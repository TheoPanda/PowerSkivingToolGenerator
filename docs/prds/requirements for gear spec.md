# 齿轮规格呈现功能模块需求文档

## 1. 概述
**用户故事**：作为齿轮刀具设计人员，我希望在生成待加工齿轮时，系统能通过一个独立窗口直观展示齿轮的单齿轮廓、2D整体轮廓及参数规格表，以便快速核对图纸与设计输入、解算信息的一致性，减少人工计算验证的工作量。

## 2. 适用角色
*   **主要角色**：齿轮刀具设计人员
*   **次要角色**：齿轮设计人员

## 3. 功能规格说明

### 3.1 窗口布局与结构
| 需求项 | 规格描述 |
| :--- | :--- |
| **整体布局** | 窗口版面设计为横向布局，采用标准的**“左图右表”**结构。左侧为图形展示区，右侧为参数列表区，确保用户能第一时间定位关键信息。 |
| **设计风格** | 窗口的UI设计风格（配色、字体、控件样式）需与主软件整体风格保持一致，保证视觉协调性。 |

### 3.2 单齿廓图展示区
*位置说明：位于窗口左侧上部区域*

| 需求项 | 规格描述 |
| :--- | :--- |
| **核心图形元素** | 必须包含齿廓线、中心线、分度线。三种线条需通过线型（实线/虚线/点划线）或颜色进行明显区分，并符合ISO相关标准。 |
| **参数标注** | 图形上需以ISO标准方式标记以下参数：<br>• 齿厚<br>• 齿距<br>• 齿顶圆角<br>• 齿根圆角<br>• 齿顶高<br>• 齿底高<br>• 齿全高 |
| **标注样式** | 标注应避免遮挡图形主体，字体大小适中，确保可读性。 |

### 3.3 齿轮2D轮廓图展示区
*位置说明：位于窗口左侧下部区域*

| 需求项 | 规格描述 |
| :--- | :--- |
| **视图内容** | 展示完整齿轮的2D投影轮廓，需清晰显示齿顶圆、齿根圆及分度圆线条。 |
| **交互功能** | 支持基本的视图操作：<br>1. **缩放**：支持滚轮或按钮缩放，以便查看齿形细节。<br>2. **平移**：支持拖拽移动视图。<br>3. **高亮联动**：鼠标悬停在某齿上时，应有相应的高亮反馈。 |

### 3.4 参数规格表区
*位置说明：位于窗口右侧区域*

| 需求项 | 规格描述 |
| :--- | :--- |
| **核心参数列表** | 必须包含以下关键参数项：<br>• 模数<br>• 齿数<br>• 压力角<br>• 螺旋角<br>• 变位系数<br>*注：其他参数根据解算结果自动填充。* |
| **数据一致性** | 表格内数值必须与左侧图形标注数值保持数学关联，修改或刷新时需同步更新。 |
| **数据交互** | 支持表格数据的选中、复制功能，方便用户导出数据至其他报告或系统。 |

## 4. UX/交互设计要求

| 交互点 | 设计要求 |
| :--- | :--- |
| **现代交互体验** | 界面响应需流畅，避免卡顿；控件交互逻辑需符合现代桌面软件习惯（如鼠标悬停提示、平滑的视图过渡）。 |
| **信息提示** | 鼠标悬停在图形元素或参数表头时，应显示悬浮提示，解释该参数的定义或计算依据，辅助用户核对。 |
| **视觉引导** | 排版需严谨、科学，通过合理的间距和对齐方式，激发用户阅览动力。 |

## 5. 验收标准

1.  **视觉验收**：窗口启动后，左侧图形与右侧表格对齐排列，无重叠遮挡；线条区分明显，符合ISO制图标准。
2.  **数据验收**：参数表中的数值与单齿廓图中的标注数值一致，且与后台解算逻辑结果误差在允许范围内（如±0.0001mm）。
3.  **功能验收**：
    *   单齿廓图清晰展示了所有规定参数（齿厚、齿距等）。
    *   2D轮廓图支持缩放和平移，无图形失真。
    *   参数表支持数据复制。
4.  **体验验收**：界面风格与主程序一致，无明显割裂感；操作过程无明显延迟。
