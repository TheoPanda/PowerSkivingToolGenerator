# 外齿轮（k_io=+1）车齿刀解析共轭路线 — 研究参考文档

**日期**：2026-08-14
**范围**：外齿轮车齿刀的**解析共轭路线**（K-2.6 生成面 / K-2.7 啮合方程 / K-2.8 刃形求交）可行性、符号链适配方式、golden 锚点与缺口。
**核心问题**：K-2.6~K-2.8 这套解析路线是否 **k_io 无关**（同一套公式对内外齿轮都成立，仅三处随 k_io 变），还是内/外齿轮在变换链/啮合方程里有**结构性符号差异**、需单独推导一套公式。
**权威源**：设计书（只读）+ repo 代码（`backend/core/common/transforms.py`、`backend/core/envelope/process_plan.py`、`swept_cloud.py`、`edge.py`）。

> ⚠️ 证据强度说明：文献 [10][11][2][23][24][25] 原始 PDF 不在本地，本文仅转述设计书第 2/4/5/6/8 章内容，凡转述处标「据设计书第 X 章转述 [N]」。设计书是权威，文献 PDF 只读回读是后续销项动作。

## 结论先行（TL;DR）

**K-2.6~K-2.8 解析路线的主体公式是 k_io 无关的**。k_io **只通过三处携带方向信息**进入，且这三处全部位于「安装方案」（模块①，已实现 `process_plan.py`）而非「变换链/啮合方程/前刀面」本体：

| 位置 | 公式 | k_io 依赖 | 代码/文档锚点 |
|---|---|---|---|
| 1. 中心距 | `a = r_pw + k_io·r_pt` | 是（内减外加） | K-1.5 / U9；`process_plan.py:92` |
| 2. 传动比 | `i = −k_io·z_w/z_t` | 是（内正外负） | [25] 式(3)；`process_plan.py:97` |
| 3. 工件齿面本身 | 内齿=齿槽/负齿数模型、外齿=齿廓 | 是（但属模块①工件侧，非②b） | ADR-015/016/017；`profile.py:724` |
| 变换链 K-0.5 | `Rot_z(−φ_t)·Tran(z,−s_t)·M_{F_t,F_w}·…` | **否** | `transforms.py:236-274` |
| 啮合方程 K-2.7 | `n·v¹² = 0` | **否** | 设计书 K-2.7 / [24] 式(2-14) |
| 前刀面 K-2.1 | `(x−r₁)sinγ + …` | **否** | `rake.py:39-64` |

关键不变量：**K-0.5 运动链只用 `φ_w/φ_t` 的实际值，不用 `i`**（据 `docs/specs/2026-08-13-discrete-envelope-spec.md:53`）。同步关系里的滚动项 `φ_w·z_w = φ_t·z_t` 与 `ω_t/ω_w = z_w/z_t` 恒正、不含 k_io（K-1.7/U10，`process_plan.py:99` 的 `omega_ratio`）。因此**内/外齿轮共用同一套变换链、啮合方程、前刀面、刃形求交代码，k_io 只改变喂给它的 `a` 标量**，不产生任何矩阵内符号翻转。

**结论：k_io 无关（无需单独推导外齿轮公式），但外齿轮解析路线缺少 golden 锚点——这是真正缺口所在，不是公式本身。**

## ① 变换链 K-0.5 是否 k_io 无关（答核心问题第 1 条）

**结论：变换链 K-0.5 完全 k_io 无关。k_io 只通过 `a` 这个标量参数进入。**

### 1.1 设计书 K-0.5 的定义（第 2 章 §2.4）

- 统一工件→刀具链：`r^(T) = Rot_z(−φ_t−Δφ_t)·Tran(z,−s_t)·M_{F_t,F_w}·Tran(z,s_w)·Rot_z(φ_w)·r^(W)`（设计书第 2 章 §2.4 K-0.5）。
- 安装变换 K-0.3：`M_{F_w,F_t} = Tran(x,a)·Rot_x(Σ)·Rot_y(δ)`（设计书第 2 章 §2.4 K-0.3）。
- 退化核对（设计书第 2 章 §2.4）明确列了三处文献对照，**无一处引入 k_io**：
  - Δφ_t=0、s_t=0、δ=0 时与 [21] 式(7) `r₂ = M⁻¹_{s2-2}·M⁻¹_{s1-s2}·M_{s1-1}·r₁` 同构；
  - 与 [24] 式(2-44) `M₂₁ = M₂p·M_p0·M₀₁` 同构；
  - 与 [25] 式(7) `M_{c′w′} = M_{c′c}·M_{cw}·M_{ww′}` 同构（[25] 的 M_cw 用 −Σ 因其方向 w→c，与 K-0.3 逆一致，C3 符号已按 U8 吸收）。

### 1.2 代码实现印证

`transforms.py` 的 `workpiece_to_tool_chain`（第 236-274 行）与 `tool_to_workpiece_chain`（第 277-314 行）签名**只接受 `a` 与 `sigma` 标量，没有 `k_io` 参数**。`install_transform`（第 217-228 行）与 `install_transform_inverse`（第 231-233 行）同样无 k_io。

### 1.3 k_io 进入链的唯一正门：`compute_process_plan`

`process_plan.py:92`：`a = r_pw + k_io * r_pt`，随后 `a` 作为纯标量喂给 `workpiece_to_tool_chain`。`swept_cloud.py:155` 调用 `workpiece_to_tool_chain(phi_w[j], phi_t[j], plan.a, sigma)` 时已丢失 k_io 信息。

### 1.4 权威佐证（spec 文档）

`docs/specs/2026-08-13-discrete-envelope-spec.md:53` 明确写道：

> K-0.5 运动链只用 φ_w/φ_t 的实际值，不用 i。

`docs/specs/2026-08-13-coordinate-axes-marker-spec.md:79` 进一步确认指针/旋转方向**不随 k_io 动态翻转**：

> 指针方向是该链瞬时正方向的示意，不随内外齿轮（k_io）动态翻转。

**小结**：k_io 不渗透进 Σ 符号、不渗透进旋转方向、不在矩阵内藏负号。U6 约定「禁止在变换矩阵内藏负号」（设计书第 2 章 U6）+ C5 转换式「[2][10] 的 Rot(z,−θ) 负号吸收进有符号角速度」保证了结构上不出现内外分支。**唯一例外**是工件螺旋面参数化 K-0.6 的 `j_w` 因子（`helical_surface`，`transforms.py:127-169`）——但 `j_w` 是**旋向系数**（右/左旋），与 k_io（内/外齿）正交独立，二者不混。

## ② K-2.6 生成面：内/外齿轮区别体现在哪（答核心问题第 2 条）

**结论：K-2.6 的两条链（Tsai 链 [10]/[2]、Guo 链 [11]）的矩阵表达式里 k_io（内/外）以 `c_g`（或 \(k_{io}\)）显式系数只出现在两处——中心距 ± 项与工件转角符号——且都已被设计书收编进 U9（中心距）与 C5（转角负号吸收）两个统一约定，不残留任何「外齿轮独有」矩阵项。**

### 2.1 Tsai 链（设计书第 2 章 §2.1.7/§2.1.8 + 第 4 章 §4.3.3）

- [2] Tsai 2021 的约定（设计书第 2 章 §2.1.7）：`c_g = +1 外齿轮、−1 内齿轮`。核心式 [2] 式(2)：`^world A_t = Tran(r_g,0,s_t)·Rot(x,Σ)·Tran(c_g(r_t+σ_g),0,0)·Rot(z,−c_g·θ_t)`。k_io（=c_g）出现在**两处**：
  1. `Tran(c_g·(r_t+σ_g),0,0)` —— 中心距符号（外 +、内 −），对应 U9/K-1.5；
  2. `Rot(z,−c_g·θ_t)` —— 刀具转角符号，且据 C5（设计书第 2 章 §2.3 C5）「引用 [2][10] 公式时，将其负号吸收进有符号角速度：θ_t,U = −c_g·θ_t,Tsai」。
- [10] Tsai 2023 式(11)（设计书第 4 章 §4.3.3 K-2.6 Tsai 链）：`^t A_g = Rot(z,−θ_t)·Tran(r_t,0,0)·Rot(y,−δ)·Rot(x,−Σ)·Tran(−r_g,0,0)·Rot(z,θ_g)`。无刀具轴倾斜角时退化为 [2] 式(35)。注意 [10] 式(11) 已把 k_io 从矩阵里**提出**（Tran 用 −r_g 固定负号、Rot(z,θ_g) 用正角），k_io 只通过「上一步算出的 a 与 Σ」进入——这与设计书 K-0.5 的「矩阵藏不住 k_io、a 才是正门」完全同构。

### 2.2 Guo 链（设计书第 2 章 §2.1.6 + 第 4 章 §4.3.3）

- [11] Guo 2023 式(1)：`M_wt = M⁻¹_{S1-w}·M_{S1-S2}·M_{S2-t}`，其中 `M_{S1-S2} = Rot(i,Σ)·Tran(i,a)`。曲面变换式(27)：`S⁽²⁾ = M⁻¹_wt·S⁽¹⁾`。
- [11] 明确针对**内齿轮**（设计书第 2 章 §2.1.6「S_w 固连工件（内齿轮）」），但其式(1) 的 `a` 与 `Σ` 是**标量参数**——按 U9，`a` 在内/外用「r_pw − r_pt」或「r_pw + r_pt」代入即可，矩阵形状不变。
- 关键设计书结论：K-2.6（设计书第 4 章 §4.3.3）明确写「离散化实现时统一用 K-0.5」——即**两条文献链最终都归一到 K-0.5 这一个 k_io 无关的统一链**，Tsai/Guo 链只作书面文献对照，不分别落实现。

### 2.3 小结

内/外齿轮在生成面构造上的区别 = 中心距 `a` 的 ±，外加一处「工件转角符号方向」（已被 C5 吸收进有符号角速度）。**两者都不是「外齿轮需单独推导」的结构性差异**，而是同一矩阵用不同标量参数代入。

## ③ K-2.7 啮合方程：k_io 怎么进入，n·v¹²=0 是否 k_io 无关（答核心问题第 3 条）

**结论：`n·v¹²=0` 是 k_io 无关的矢量不变式。k_io 不显式出现在啮合方程里，它只通过「相对速度 v¹² 的具体分量」间接进入——而 v¹² 的分量方向已由同步滚动项 `φ_w·z_w = φ_t·z_t`（恒正，无 k_io）与中心距 `a`（标量）唯一确定。**

### 3.1 设计书 K-2.7 的四种文献形式（第 4 章 §4.3.3）

| 形式 | 源 | 是否含 k_io 显式项 |
|---|---|---|
| `n·v⁽¹²⁾ = 0` | [24] 式(2-14)（主实现） | 否 |
| `∂^t r_g/∂θ_g · ^t n_g = 0` | [10] 式(15) | 否 |
| `(∂r_pg/∂α × ∂r_pg/∂z_g)·v = 0` | [3] 式(3) | 否 |
| `(∂r_h/∂u × ∂r_h/∂ζ)·∂r_h/∂φ_t = 0` | [14] 式(19) | 否 |

设计书 K-2.7 明确「主实现：[24] 通用形式（符号体系与 U 约定最接近）」。

### 3.2 v¹² 的定义与 k_io 位置

[24] 式(2-6)（设计书第 2 章 §2.1.5 转述）：`v⁽¹²⁾ = ω⁽¹⁾×r⁽¹⁾ − ω⁽²⁾×r⁽²⁾ + v₀⁽¹⁾ − v₀⁽²⁾`。其中 ω⁽¹⁾、ω⁽²⁾ 是**有符号角速度**（U6），其符号由「滚动啮合 + 进给差动」决定：
- 滚动项 `ω_t/ω_w = z_w/z_t` 恒正（U10/K-1.7），**不含 k_io**（`process_plan.py:99` 的 `omega_ratio`，spec §53 也强调「ω_t/ω_w = z_w/z_t 恒正」）。
- 进给差动项 `Δω_w = s_d·v_f·tanβ_w/r_w`（U10）用 `s_d` 系数（进给轴向决定），**不是 k_io**；且两算例 β_w=0 时恒为零。

因此 v¹² 不含任何内/外分支逻辑。k_io 只在「多齿啮合时 ω⁽¹⁾ 与 ω⁽²⁾ 的相对旋向」体现为**符号**，但该符号正是 `i = −k_io·z_w/z_t` 这个**标量输出的物理解释**（`process_plan.py` dataclass 注释第 19-20 行：「i 传动比 = −k_io·z_w/z_t（含内外啮合方向；外齿轮为负、内齿轮为正）」）。**K-0.5 与啮合方程都不消费 `i`，只消费 `φ_w/φ_t` 与 `a`**——spec §53 一句话点透：「K-0.5 运动链只用 φ_w/φ_t 的实际值，不用 i」。

### 3.3 小结

`n·v¹²=0` 是矢量形式，内/外齿轮代入同一套几何量（同一中心距公式、同一滚动同步）后自然成立，方程本体无需改写。

## ⑤ golden 锚点缺口：外齿轮解析路线需要什么（答核心问题第 5 条）

**现状（设计书 testdata 三份 JSON，§6.4 + testdata/）：**

| testdata | 路线 | 工件 | 锚点性质 |
|---|---|---|---|
| `ex1_analytic.json` | 解析 | 内直齿轮 z=82 | 参数级硬锚点（[23] 表3.3 八项参数）；🔴 刃形点坐标未发表（T5）|
| `ex2_discrete.json` | 离散 | 内谐波 z=102 | 参数/矩阵/单点轨迹参考基准；🔴 齿廓/离散参数未发表（T3/T4）|
| `ex3_jia2019_cases.json` | 离散 | 外廓形 Z_w=7 / 内廓形 Z_w=20 | 参数级自洽（d=i 自洽、Σ 翻号）；🔴 刃形坐标未发表（T6）|

**关键事实：三份 testdata 里没有任何「外齿轮 + 解析」算例。** 外齿轮解析落地面临三重缺口：

### 缺口 G1：无外齿轮解析硬锚点（参数级 / 点级均缺）

- 内齿轮解析靠 [23] 表3.3 八项修正参数做硬锚点（第 7 章行 3：角度 <0.005°、直径 <0.002mm）。**外齿轮无对应文献表**——[23]/[11] 都是内齿轮。
- 不能从 [25] 算例3 外廓形推导解析 golden：它走**离散**路线、刃形坐标未发表（T6）、且其外廓形 Z_w=7 是小齿数非渐开线（廓形参数 φ_w 起止由 R_w=27.5 推，非标准渐开线齿高），**不适合作解析共轭的渐开线基准**。

### 缺口 G2：「双向包络自证 + 对称性」充其量是**弱兜底，不是独立锚点**

- 正向/反向包络共享同一变换链时，符号 bug 会互相抵消（`edge.py` module docstring 第 7-8 行已有明示：「ffα 只证闭环自洽非绝对正确」；spec §31 同）。这对外齿轮**一样成立**——所以外齿轮解析路线**不能只靠 ffα 自证闭环**。
- 唯一的独立锚点来源是「内外齿轮共用同一公式的**对称性**」+「内齿轮算例1 已验」。但这是**间接**锚点：它只能证「外齿轮公式 = 内齿轮公式随手换 k_io」，不能独立证「这套公式绝对值正确」。
- 若想拿到**绝对正确性**，仍需一个「外齿轮 + 解析 + 刃形点坐标」的文献/实测数据，或「外齿轮解析 ↔ 外齿轮离散（[25]/[21] 方法跑外齿轮）双路线互检」的定量结果。

### 缺口 G3：可计算的硬断言（不依赖文献的外齿轮自检）

尽管文献锚点缺，下列**几何不变量**可作为外齿轮解析的**派生根**（类似内齿轮 ex2 自洽检验，design book 第 7 章行 1/2 体系）：

1. **中心距自洽**：外齿轮 `a = r_pw + r_pt`（`ex3` 外廓形 `d = R_w + k_io·R_c = 62.857` 已验证，`process_plan.py` 可加外齿轮正例单测）。
2. **传动比符号**：外齿轮 `i = −z_w/z_t` 负（`ex3` 外廓形 `i = −7/9`，spec §123 已列作参考基准）。
3. **同步比不变量**：`ω_t/ω_w = z_w/z_t` 恒正，内外一致。
4. **退化为离散互检**：用**同一外齿轮参数**跑 K-2.9~2.13 离散路线（`generate_envelope_cloud` + `extract_edge` 已支持 k_io=+1，见 `swept_cloud.py:98-112` 的 `extract_gap_points` 分支——外齿用 `_tooth_open_segments`）与解析路线（K-2.6~2.8）对拍，取第 5 章 §5.5 的双路线互检 ε_cross=1μm。**这是当前唯一能产生外齿轮「相对正确性」锚点的可执行路径**。

## 落地清单与建议锚点组合

**结论回答**：**k_io 无关，无需单独推导外齿轮公式。** 同一套 K-0.5/K-2.6/K-2.7/K-2.8 代码，k_io 只通过 `a` 标量（+ 工件齿面侧按 ADR-015/016 选择齿廓/齿槽）适配。外齿轮解析路线落地的**真正工作不是推导，而是补锚点与补回读**：

| 优先级 | 动作 | 类型 |
|---|---|---|
| P0 | **外齿轮解析 ↔ 外齿轮离散双路线互检**（ε_cross=1μm，第 5 章 §5.5），作为外齿轮「相对正确性」锚点 | 派生锚点（可立即做，代码已支持 k_io=+1 离散）|
| P0 | `process_plan.py` 加**外齿轮正例单测**：`a = r_pw + r_pt`、`i < 0`（对照 `ex3_jia2019_cases.json` 外廓形 62.857 / −7/9）| 硬断言（无文献依赖）|
| P1 | 回读 [10][2] 排版混乱页（W10/W11）确认 Tsai 链外齿轮（c_g=+1）矩阵元素，消除「外齿轮矩阵项」不确定性 | ⚠️ 缺口销项 |
| P1 | 回读 [24] p.30-48 矩阵乱码（W12），确认真通用啮合方程主实现无隐藏符号假设 | ⚠️ 缺口销项 |

## 附：内/外齿轮在「工件齿面侧」的实际差异（模块①，非②b）

为完整性澄清「三处随 k_io 变」中第 3 处的**真实位置** —— 它在模块①（工件建模），不在模块②b 的解析公式里：

- **内齿**（k_io=−1）：用**齿槽/负齿数模型**。齿槽 = 刀具齿的反包络源（ADR-017），`extract_gap_points` 走 `tooth_gap_segments`（`swept_cloud.py:108-109`）；几何上材料在齿面外侧（d_a 小径、d_f 大径），齿廓手性与外齿互补（ADR-016，`profile.py:724-732` 左右齿面模板镜像对调）。
- **外齿**（k_io=+1）：用**齿廓**，`extract_gap_points` 走 `_tooth_open_segments`（开放单齿轮廓，`swept_cloud.py:110-111`）。

这处差异对**离散路线**已落地（`swept_cloud.py` 已分支）。对**解析路线**，它同样只影响「喂给 K-0.6 螺旋面参数化的廓形函数 \(x_0(u), y_0(u)\)」，不改变 K-2.6~2.8 的公式结构——再次印证 k_io 无关。

## 采纳/备忘

- **核心结论**：外齿轮解析路线 **k_io 无关**，同一套 K-0.5/K-2.6/K-2.7/K-2.8 公式，k_io 仅经「a = r_pw + k_io·r_pt（K-1.5/U9）」+「i = −k_io·z_w/z_t（[25] 式(3)）」+「工件齿面选齿廓/齿槽（模块①）」三处进入，无一渗透进矩阵/啮合方程/前刀面符号。
- **下一步子 PRD-5（解析路线）编写时**应显式声明：外齿轮按「k_io=+1 代入同一实现」处理，不新增公式分支；验收锚点按本文 P0 组合（双路线互检 + ex3 外廓形硬断言）执行。
- **对外沟通点**：设计书第 8 章建议新增 T14 项（外齿轮解析无文献 golden），避免后续 spec 把「内外共用公式 = 已验证」错误升格为硬门禁。
