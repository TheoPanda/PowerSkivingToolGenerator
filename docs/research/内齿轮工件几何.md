## ① 负齿数模型的公式集与符号约定（答调研①，high confidence）

内齿轮与外齿轮几何**刚好镜像**——内齿轮材料位于齿面**外侧（环侧）**：

| 量 | 外齿轮 | 内齿轮 |
|---|---|---|
| 齿顶圆（大径/小径） | `D_a = D + 2·h_a`（大） | `D_a = D − 2·h_a`（**小**，内侧） |
| 齿根圆（小径/大径） | `D_f = D − 2·h_f`（小） | `D_f = D + 2·h_f`（**大**，外侧） |

其中 `D = m_t·z`，`h_a = h_an·m_n`，`h_f = (h_an + c_n)·m_n`。

**变位后表达式（ISO 21771 / AGMA 2002-D19 / GB/T 3374.1-2010 负齿数模型）**，`x` 与齿厚同号：

```
s_t = π·m_t/2 + 2·x_w·m_n·tan(α_t)        # 分度圆齿厚，+x → 内齿变厚（与外齿轮同式）
d_a = z·m_t − 2·(h_an + x_w)·m_n          # 齿顶小径，+x → 更小（进一步内移）
d_f = z·m_t + 2·(h_an + c_n − x_w)·m_n    # 齿根大径，+x → 更小
```

**全齿高不变量（硬自检，实现必加断言）**：

```
h = (d_f − d_a)/2 = 2·h_an + c_n     # 与 x_w 无关
```

**内啮合总变位系数取减号**：`xΣ = x2 − x1`（外啮合为 `x1 + x2`）——这是负齿数模型把外齿轮渐开线函数式代入 `z2 = −|z2|` 的代数等价表达。属于**啮合副**层，留待模块②。

⚠️ 注意：存在历史反号流派（DIN 3960 旧版 / AGMA 913-A98，+x 使内齿变薄），已被 AGMA RFI 25-01 官方认定有误，GB/T 3374.1-2010 跟随 ISO。**本项目采纳 ISO 约定，不混用。**

来源：[FreeCAD commit 5fa3e02](https://github.com/FreeCAD/FreeCAD/commit/5fa3e021e894cc835217607577d2e86f3acb302e)（内齿 `root = pitch + 2·ded·m`）、[Autodesk Fusion 内齿轮概念](https://forums.autodesk.com/t5/community-blog-d-m-english/autodesk-fusion-how-to-understand-involute-gears-and-create/ba-p/13835000)（内齿顶为内侧小径）、[JLC 齿轮手册 14035](https://www.jlc-jdgf.com/mcbook/14035.htm?type=search)（内啮合 xΣ=x2−x1）。

## ② 内齿轮跨棒距 M 与公法线 W_k（答调研②）

**跨棒距 M**（high confidence）：
- 内齿轮 M 是**跨齿槽内两量棒之间**：`M = 量棒中心圆直径 − d_p`（恒为减，never plus）。
  - 偶数齿：`M = D_p − d_p`；奇数齿：`M = D_p·cos(90°/N) − d_p`，其中 `D_p = d_b/cos(α_p)`。
- 因此 `M = d_b/cos(α_M) − d_p` 正确（⟺ `cos(α_M) = d_b/(M + d_p)`）——**与设计书 K-1.11 及现有代码 `back_solve_x_w_from_M` 一致**。
- 斜齿需先做法向→端面换算（`m_t`、`α_t`、基圆螺旋角 `β_b`、虚拟端面量棒径 `d_pt = d_p/cos(β_b)`）；**2026-08-12 更新：内斜齿已落地（ADR-017，spec §11），但 M 沿用直齿近似**（与既有外斜齿一致），真斜齿 over-balls 的 `β_b`/`d_pt`/`z_v=z/cos³β` 三项换算仍留档后续 ADR。

**量棒径选择**（medium confidence）：内齿轮推荐 `d_p ≈ 1.44 × m_n`（外齿轮约 `1.68 × m_n`；Machinery's Handbook 规则换算）。实际取决于齿面接触点，须避开齿顶/齿根。

**公法线 W_k**（high confidence）：
- 内齿轮理论可用公法线测量，但**几何定义与外齿轮不同**：
  - 外齿轮跨 **k 个齿**：`W_k = (k−1)·P_bn + s_bn`
  - 内齿轮跨 **k 个齿槽**：`W_k = k·P_bn + s_bn`（差一个基节）
- 工程上内齿轮公法线**难用切向卡规测量** → 实测普遍以跨棒距 M 为主。
- **结论：内齿轮模块应以 M 为主要计量输入；W_k 不作为内齿主检测输入。**（本项目 Q2 决策：内齿 UI 禁用公法线，保留 x_w/M。）

来源：[KHK 跨棒距计算 PDF](https://www.khkgears.us/media/1276/how-to-calculate-the-nominal-values-of-over-pin-or-ball-measurement-of-teeth-for-various-types-of-gearing.pdf)、[IGS Gear 齿厚/公法线/跨棒距关系](https://igsgear.com/kb/what-are-the-definitions-and-relationships-between-tooth-thickness-base-tangent-length-and-measurement-over-pins/)、[SDP-SI 内齿轮技术信息](https://shop.sdp-si.com/products/gears-differentials-pinions-racks/internal-gear-technical-information.html)、[QTC 齿厚 PDF](https://pdf.directindustry.com/pdf/quality-transmission-components/tooth-thickness/11708-151885.html)、[zhygear CAXA 内齿轮跨棒距](https://www.zhygear.com/utilizing-caxa-graphic-method-for-determining-internal-gear-measurement-over-pins/)。

## ③ 可行性与干涉约束（答调研③）

**孤立工件层**（本模块范围内）：
- **渐开线有效齿廓要求 `d_b < d_a`**（齿顶小径在基圆之外）。标准 20°、x=0 时在 **z ≥ 34** 成立（`d_b = d_a` 跨界点 z≈33.16）；**z ≤ 33 时 `d_b ≥ d_a`，齿顶落入基圆内，渐开线无法延伸至齿顶**。
- 推荐**正变位 `x_w > 0`**：有利于避免渐开线干涉与径向干涉（方向性建议，非绝对保证；过度变位致齿顶变尖，精确上限未定义）。

**啮合副层**（需配对齿轮输入，**超出孤立工件建模范围**，留待模块②）：
- 三类齿顶干涉——(i) 渐开线干涉（小齿轮齿根↔内齿轮齿顶，标准 20° 需 z2>34 的齿顶压力角条件避让）；(ii) 摆线/过渡曲线干涉（小齿轮齿顶↔内齿轮齿根，齿数差 z2−z1>9 时避免）；(iii) 径向修剪干涉（径向装配/切削受限，需轴向滑移）。

来源：[Autodesk Fusion 内齿轮概念](https://forums.autodesk.com/t5/community-blog-d-m-english/autodesk-fusion-how-to-understand-involute-gears-and-create/ba-p/13835000)、[JLC 手册](https://www.jlc-jdgf.com/mcbook/14035.htm?type=search)、[SDP-SI 内齿轮](https://shop.sdp-si.com/products/gears-differentials-pinions-racks/internal-gear-technical-information.html)。

## ④ 齿廓构造细节（答调研④，high confidence）

- 内齿轮**齿顶弧与齿根弧的凸向必须与分度圆同心**（材料在齿面外侧/环侧）。把外齿轮齿廓直接移植到内齿轮时，**仅将齿顶弧与齿根弧的方向标翻转**（FreeCAD 源码 `arc direction 0→1`，`align` 使与分度圆同心），渐开线齿面本身形状不变。
- 当齿顶点不在渐开线可用域内（`tipWithinInvolute==False`，即 ③ 的 `d_b ≥ d_a` 情形），FreeCAD 用**直段衔接**：从齿顶圆向下画线到基圆（对称侧从基圆向上），非纯渐开线+双切圆角。这是 FreeCAD 的工程化简化，**不代表 ISO 标准齿廓**。
- 内齿轮齿根/齿顶**双切圆角**的等价构造可行性，本次调研**未获直接主源证实**——本项目 Q3 决策（内齿 v1 禁用齿顶/齿根修饰）与之相符，留待后续。

来源：[FreeCAD commit 5fa3e02](https://github.com/FreeCAD/FreeCAD/commit/5fa3e021e894cc835217607577d2e86f3acb302e)（主源，full_patch 逐字验证：弧方向翻转 + 条件直段锚定）。

## 被否决的主张（勿采用）

- 理想量棒径 `d_p* = 2m·cosα·(invφ+η)`（1-2 否决）
- W_k 通用闭式 `W_k = m·cosαf·[(k−0.5)π + z·inv(αf)]` 不分内外（0-3 否决；此式只对**外**齿轮跨 k 齿成立）
- W_k 变位项符号内/外翻转（1-2 否决——内齿轮不是"外齿轮公式翻 x"）
- 量棒中心齿槽半角 `η = π/2z − invα`（0-3 否决）
- KHK 表7 偶数/奇数齿跨棒 R_c 公式（1-2 否决）
