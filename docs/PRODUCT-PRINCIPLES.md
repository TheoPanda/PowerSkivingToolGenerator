# 车齿刀设计软件 · 产品三件套

> 作用：管线的「种子」。愿景→PRD→spec 逐级细化时，本文件全程作为硬约束。

## 一、愿景（1 句 · 兜底裁决）

> 以微米级精度，把专家的车齿刀设计能力交到每一位工程师手中——定义齿轮精密加工的数字化标准。

*用法：仅当下面所有规则都覆盖不到的灰色地带，用这句话定方向。平时不干预具体决策。*

## 二、原则（横切护栏 · 贯穿每一层）

| # | 原则 | 不可违反的底线（不变式） |
|---|------|------------------------|
| P1 | 精度即底线 | 导出的模型/图纸几何误差 ≤ ±1μm，且可溯源到 ISO 条款 |
| P2 | 渐进式专业 | 新用户零配置、不查手册即可跑通一次标准设计 |
| P3 | 闭环即价值 | 每个功能都在「参数→建模→校验→输出」主链路上 |
| P4 | 知识可沉淀 | 设计决策上下文自动记录，用户零额外操作 |
| P5 | 可信即体验 | 系统主动校验参数并给出设计建议；一切建议/告警必带依据，无依据则不给 |
| P6 | 工业美学 | 所有界面遵循统一设计规范（见 `docs/DESIGN-SYSTEM.md`），传达「精密、可信赖」的工业仪器气质；禁止未约束的默认控件与卡通化元素 |

**冲突仲裁：编号小者胜（P1 > P2 > P3 > P4 > P5 > P6）。** 唯一缓冲——P1 与 P2 冲突时精度获胜，但用渐进呈现承接。P6 投入优先级极高，但冲突仲裁时让位于 P1–P5。

## 三、验收标准（spec 的可测试条目 · 趁早定）

> 这就是「早期衡量决策」的真身：不是新文档，是 spec 里要验收的测试，提前锁定。

| 指标 | 怎么测（仪器/方法） | 通过阈值 |
|------|-------------------|---------|
| 几何精度 | 黄金样本库 + CI 回归，对权威解比对 | 全部样本关键几何量偏差 ≤ 1μm，超标阻断发布 |
| 上手速度 | 标准任务计时（新用户、无手册） | 完成率 ≥ 90%，中位耗时 ≤ 5 分钟 |
| 设计效率 | 同型刀具「软件 vs 传统」周期对照 | 周期比 ≤ 0.5，首版通过率 +80% |
| 专家赋能 | 独立完成任务占比（埋点区分独立/求助） | 初级工程师独立率 ≥ 60% |

---

## 接入管线（3 步）

1. **生成 PRD**：提示词声明「受 P1–P5 约束，冲突按编号仲裁」。
2. **生成 spec**：每条需求标注它满足哪条原则、对应哪条验收标准；标注不出的条目回审。
3. **验收**：第三节表格逐条转成测试用例（±1μm 回归、5 分钟计时、独立率埋点等）。
